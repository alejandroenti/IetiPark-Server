# 🎮 IetiPark - Server

Servidor de WebSockets desenvolupat amb **Node.js** que gestiona les comunicacions en temps real entre el joc **IetiPark** (LibGDX) i la interfície web (Flutter). A més, s'encarrega de la lògica del joc.

## 📋 Descripció

IetiPark Server actua com a punt central de comunicació del projecte IetiPark:

- **Comunicació en temps real** — Gestiona connexions WebSocket entre els clients del joc i la web.
- **Lògica del joc** — Processa i gestiona la lògica principal del joc IetiPark.
- **Pont entre plataformes** — Connecta l'aplicació LibGDX amb la interfície web Flutter.

## 🚀 Instal·lació

```bash
# Clona el repositori
git clone https://github.com/alejandroenti/IetiPark-Server.git
cd IetiPark-Server

# Instal·la les dependències
npm install

# Inicia el servidor
node --run start-server
```
